This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

Personal Finance Visualizer is a web-based application that helps users manage their money more effectively. It allows users to track income and expenses, visualize spending through interactive charts, and set monthly budgets to control expenses. As an extension that can work alongside platforms like GPay, it provides clear insights into transactions, alerts users when they approach budget limits, and helps them make informed financial decisions in a simple and user-friendly way.

---

## Setup

Make sure you have the following installed:

- Node.js / NPM (for frontend)
- Python / virtual environment (for backend)
- Git

## Navigate 

- git clone https://github.com/Vaishnavi-Barhate/personal-finance-visualizer.git
- cd personal-finance-visualizer

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
